Méthode et suivi

Le modèle note chaque cheval de 0 à 100, à partir de sept critères. Voici leur poids :

  • musique : 25 %
  • Aptitudes à la distance : 18,75 %
  • Forme : 18,75 %
  • Chronos : 15 %
  • Tandem driver-entraîneur : 7,5 %
  • Conditions : 7,5 %
  • Bruits d'écurie : 7,5 %
  1. La note est une moyenne pondérée. Une donnée absente compte pour la moyenne neutre (0,5).
  2. Simulation de 200 000 arrivées : à chaque tirage, le cheval le mieux noté a le plus de chances de passer en premier, les autres suivent selon leur note (sensibilité 4).
  3. Chances : part des simulations où chaque cheval gagne, finit dans les trois premiers ou dans les cinq premiers.
  4. Le pronostic est celui du soir, figé vers 23 h, et il ne change plus. Un non-partant déclaré après ce figement reste signalé dans la liste.
